# CS-46 — Release Equipment Reservations After Event Cancellation

Sources: [CS-46 Jira](https://spmg8.atlassian.net/browse/CS-46) and the test-case spreadsheet, Sprint 4 rows 46–53. The Equipment release endpoint verifies the exact Event-service cancellation proof and writes an idempotent release history/outbox action; the shared relay publishes that action. CS-54 owns the whole-Event cancellation orchestration and must call this Equipment endpoint. No CS-54 files or behavior are changed here. Notification delivery is outside this story. Dates below record creation of this Markdown specification, not the original spreadsheet cases.
