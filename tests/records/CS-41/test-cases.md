# CS-41 — Test Case Specification (IS212 / IEEE 829)

Date of Creation: 2026-10-17T18:00:00+08:00. Jira is authoritative. The current code derives the equipment period from Booking's `occupiedStartAt`/`occupiedEndAt` values, which include venue setup/turnaround; this does not establish Jira's independent zero-buffer policy and is reported as a coverage/implementation gap below.

## Current Jira-aligned specification — 29 October 2026

Case 12 is a historical supplement whose buffered-period expectation conflicts with Jira's zero-buffer policy; it is documented but has no active executable test. Cases 13–14 are repository-only Unit supplements.
